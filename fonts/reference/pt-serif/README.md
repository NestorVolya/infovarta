# PT Serif — російська контрольна антиква (ParaType, 2010)

**Порівняльний фонд, а не гарнітура «Рутенії».** Підбір для зіставлення із Zakon. Окремо від 14 гарнітур Василя Чебаника.

**Основне накреслення для порівняння:** [PT Serif Regular](PT_Serif-Web-Regular.ttf).

Доступні також [Italic](PT_Serif-Web-Italic.ttf), [Bold](PT_Serif-Web-Bold.ttf), [Bold Italic](PT_Serif-Web-BoldItalic.ttf), [Caption Regular](PT_Serif-Caption-Web-Regular.ttf) і [Caption Italic](PT_Serif-Caption-Web-Italic.ttf).

Документація: [джерело, авторство та перевірені Git-хеші](SOURCE.md). Ліцензія: [SIL OFL 1.1](OFL.txt).

Вихідні TTF-файли з `google/fonts` збережено без модифікацій. Назви, атрибуція й історичний контекст не є доказом залежності між PT Serif і Zakon.
